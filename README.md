# Cuero Norte Tapicería — demo conceptual

Sitio web estático, responsive y completamente ficticio para demostrar una dirección de diseño en español para un negocio de tapicería automotriz.

## Avisos

- Cuero Norte no es un negocio real.
- El correo, ubicación y textos comerciales son demostrativos.
- El formulario no transmite ni almacena datos.
- Todas las fotografías fueron generadas con IA para este proyecto.
- No se reutilizaron fotografías, logotipos, textos ni datos de los sitios investigados.

## Abrir localmente

```bash
python3 -m http.server 8080
```

Visita `http://localhost:8080`.

## Archivos

- `index.html` — estructura y contenido
- `styles.css` — sistema visual y diseño responsive
- `script.js` — navegación móvil, comparador, materiales y formulario demostrativo
- `assets/images/` — imágenes originales generadas para la demostración

## Publicación

Diseñado para GitHub Pages desde la rama `main` y la raíz del repositorio.
